# Raamatukogu
Milline on DbContext-i ülesanne?
Dbcontexti ülessanne on ühendada programm andmebaasiga

Miks ei ole hea paigutada kõiki andmebaasipäringuid otse kasutajaliidese koodi?
See ei ole hea sest rakendus muutub raskemaks. Kasutajaliides peab ainult tegelema andmete vastuvõtmisega

Millisesse kihti paigutaksid andmebaasiga suhtlemise MVC- või VIPER-arhitektuuris?
MVC paigutaksin modeli kihti kuna see eraldab andmebaasi loogika esitlusest ja kontrollerist
